# ATOF Specification Has Moved

The canonical Agent Trajectory Observability Format (ATOF) specification is now
maintained in NVIDIA NeMo Relay:

<!-- markdown-link-check-disable -->
- [ATOF Core Specification source](https://github.com/NVIDIA/NeMo-Relay/blob/main/docs/reference/atof-event-format.mdx)
- [Rendered ATOF Core Specification](https://docs.nvidia.com/nemo/relay/dev/reference/atof-event-format)
<!-- markdown-link-check-enable -->

NVIDIA NeMo Agent Toolkit continues to provide the Python consumer, test
producer, and [ATOF-to-ATIF conversion examples](./examples/atof_to_atif/README.md).
This forwarding page preserves existing links while keeping the normative
specification in one repository.
